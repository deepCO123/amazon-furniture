AMAZON logo pack
svg/  : الأفضل للموقع (حاد في أي حجم، حجمه صغير)
png/  : خلفية شفافة للاستخدام العام (سوشيال، فواتير، تصميمات)
icons/: favicon + أيقونة التطبيق + صورة المشاركة (1200x630)

الأنواع:  amazon-logo-*  = العلامة + الاسم + الشعار النصي (عمودي)
          amazon-horizontal-* = العلامة + الاسم (للهيدر)
          amazon-mark-* = العلامة فقط
الألوان:  color  = نحاسي متدرج (للخلفيات الغامقة)
          bronze = برونزي غامق (للخلفيات الفاتحة)
          white  = أبيض
